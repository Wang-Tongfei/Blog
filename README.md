# Tongfei Wang · Personal Website

A bilingual portfolio with projects, experience, skills, and contact details. Switch between Chinese and English using the header button.

Static HTML, CSS, and JavaScript. Published through GitHub Pages from the main branch root. Edit profile.js for personal and project data, main.js for page content, and i18n.js for translations.
